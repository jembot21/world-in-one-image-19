# The World in One Image — Thursday 19 November 2026

One readable 1024×1024 newspaper-style image that sums up the world's news for Thursday 19 November 2026, spanning major stories, regions, fields, and a compact date check.

`draw.py` renders `entry.png` from `stories.json` with Pillow. `main.py` is the contest program that writes `/output/entry.png`.

Sources: Reuters, BBC, AP, The New York Times, Le Monde and other wires, 19 November 2026.
